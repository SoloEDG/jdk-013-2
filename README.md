# 潮汐之间

安装：`npm install`

本地启动：`npm run dev`

类型检查：`npm run typecheck`；生产构建：`npm run build`；单元测试：`npm test`。

Docker 启动：`docker compose up --build`，访问 http://localhost:8133 。

## 双窗口导览

展厅的两块屏幕在同一浏览器中以两个标签页打开，分别选择「讲解员控制屏」与「观众观看屏」，经 `BroadcastChannel` 直连，无需后端。

- **同步范围可选**：讲解员可切换「仅同步位置」（章节 / 时间 / 播放态）或「位置 + 视角」（额外带动 360° 镜头）。
- **控制权清晰**：导览期间主线控制权归属讲解员，观众侧播放、拖动、切章自动锁定，并显示「由谁接管」；观众仍可点开热点临时查看人物支线，期间主线不被打断，返回时回到讲解员**当前**主线。
- **原子收敛**：切章、进入 / 退出访谈等结构性操作以整屏快照（章节 + 时间 + 视角 + 热点 + 支线）原子下发，两屏最终章节与热点必然一致，不会只同步一个时间数字。
- **防倒退重连**：每条消息带 `epoch`（会话号）+ `seq`（单调序号）。重连后讲解员以新 epoch 重新建链，旧会话迟到命令、重复 / 乱序的旧命令一律被丢弃。
- **控制窗关闭**：讲解员关闭控制窗或结束导览后，观众屏收到通知并解锁，可继续独立观看。
- **收藏隔离**：讲解员与观众的探索手记使用各自独立的本地存储命名空间，导览协议从不携带收藏数据，互不覆盖。

### 代码结构

双屏能力集中在 `src/features/guide/`：

- `model/protocol.ts`：消息协议、防倒退闸门、收敛计划（纯函数，可单测）。
- `lib/transport.ts`：`BroadcastChannel` 传输封装（跨设备可替换为 WebSocket，上层协议不变）。
- `model/hostSession.ts` / `model/viewerSession.ts`：讲解员主控与观众跟随会话。
- `lib/reconcile.ts`：按计划把远端场景原子收敛到本地工作区。
- `ui/`：角色选择屏与导览控制条。

`src/app/workspace.ts` 负责把导览会话与既有播放、视角、热点、访谈、手记装配起来，并通过依赖注入支持测试用内存传输。
